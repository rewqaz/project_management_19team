# Фаза 3. Оценка проекта

В третьей фазе мы описали 12 вариантов использования сервиса регистрации на студенческие события, включая основные, альтернативные и негативные сценарии. UC4 «Регистрация на мероприятие» дополнительно разбили на пользовательские истории и вертикальные срезы.

Результаты трёх методов:

| Метод | Результат |
| --- | ---: |
| COSMIC Function Points | 170 CFP |
| Use Case Points | 127,284 UCP; 2 545,7 чел.-ч |
| Покер планирования | 105 чел.-дней; 840 чел.-ч |
| Экспертная оценка полного цикла | 1 527,3 чел.-ч |
| Рабочая базовая оценка | 2 036,5 чел.-ч |

Для плана мы приняли диапазон 1 527–2 546 чел.-ч, резерв 20% и срок 4 месяца для команды 4,5 FTE. Сокращённый вариант без UC6, UC11 и UC12 оценивается в 1 572,2 чел.-ч, что на 22,8% меньше базовой оценки полного варианта.

Все исходные данные, промежуточные расчёты и формулы находятся в книге [«Фаза 3 Оценка проекта.xlsx»](Фаза%203%20Оценка%20проекта.xlsx).
