# Фаза 2. Распределение работы

Во второй фазе мы декомпозировали фазу 3 на 18 работ: 15 индивидуальных и 3 коллективные. Каждый участник независимо оценил трудоёмкость и предпочтительность индивидуальных задач. Итоговую трудоёмкость определяли медианой четырёх оценок.

Затем мы решили задачу целочисленного распределения: максимизировали сумму предпочтений, ограничили индивидуальную нагрузку диапазоном 7,5–10 часов, запретили назначения с оценкой 1 и сохранили у одного исполнителя связанные пары COSMIC и UCP.
