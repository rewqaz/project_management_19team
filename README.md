# Проектный менеджмент — команда 19

В репозитории находятся материалы по Фазе 1: сравнение четырёх концепций программного проекта методами нечёткого коллективного TOPSIS и чёткого коллективного МАИ.

| Раздел | Содержание |
| --- | --- |
| [Фаза 1 — Выбор концепции проекта](Фаза%201%20-%20Выбор%20концепции%20проекта/README.md) | Концепции, модельные оценки, расчёты и вывод |

По модельным данным оба метода рекомендуют **A3 — сервис регистрации на студенческие события**. Оценки созданы как четыре демонстрационных профиля M1–M4. Они не являются индивидуальными ответами участников команды; для окончательного командного решения их нужно заменить реальными оценками и повторить расчёт.

Таск-трекер ведётся на [доске YouGile](https://ru.yougile.com/board/nb0783gl8x30) как отдельный проект, поэтому папки таск-трекера здесь нет. Исполнители, периоды и чистое время работ должны фиксироваться на доске.

В исходном задании указана группа из трёх человек. Фактический состав команды — четыре человека; это расхождение следует согласовать с преподавателем.
