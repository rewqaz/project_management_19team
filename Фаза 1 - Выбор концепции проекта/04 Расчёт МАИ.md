# Чёткий коллективный МАИ

Модель выбора содержит цель, четыре критерия C1–C4 и четыре альтернативы A1–A4. Для каждого из четырёх модельных профилей построено пять взаимно обратных матриц `4 × 4`: одна для критериев и по одной для альтернатив относительно каждого критерия.

## 1 Агрегирование суждений

Для каждой пары элементов групповое сравнение определяется геометрическим средним четырёх индивидуальных значений: `aᵢⱼ = (aᵢⱼ¹ aᵢⱼ² aᵢⱼ³ aᵢⱼ⁴)^(1/4)`. Это сохраняет взаимную обратность матриц. Групповая матрица критериев:

|  | C1 | C2 | C3 | C4 |
| --- | ---: | ---: | ---: | ---: |
| C1 | 1,0000 | 1,0000 | 2,2134 | 1,1892 |
| C2 | 1,0000 | 1,0000 | 2,2134 | 1,1892 |
| C3 | 0,4518 | 0,4518 | 1,0000 | 0,4518 |
| C4 | 0,8409 | 0,8409 | 2,2134 | 1,0000 |

Приоритет строки — её геометрическое среднее, разделённое на сумму средних всех строк. Получены веса:

| Критерий | Групповой вес |
| --- | ---: |
| C1 | 0,3020 |
| C2 | 0,3020 |
| C3 | 0,1307 |
| C4 | 0,2652 |

## 2 Локальные и глобальные приоритеты

| Альтернатива | По C1 | По C2 | По C3 | По C4 | Общий приоритет | Место |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A1 | 0,1926 | 0,1564 | 0,2965 | 0,2460 | 0,2094 | 4 |
| A2 | 0,2249 | 0,3551 | 0,1389 | 0,1298 | 0,2278 | 3 |
| A3 | 0,3263 | 0,2788 | 0,3377 | 0,2801 | **0,3012** | **1** |
| A4 | 0,2562 | 0,2096 | 0,2270 | 0,3442 | 0,2616 | 2 |

Общий приоритет альтернативы — сумма четырёх произведений локального приоритета на вес соответствующего критерия. Например, A3: `0,3020×0,3263 + 0,3020×0,2788 + 0,1307×0,3377 + 0,2652×0,2801 ≈ 0,3012`.

## 3 Проверка согласованности

Для каждой групповой матрицы `λmax = среднееᵢ[(Aw)ᵢ/wᵢ]`, `CI = (λmax−4)/3`, `CR = CI/0,90`. Здесь `0,90` — индекс случайной согласованности для порядка 4.

| Матрица | CR |
| --- | ---: |
| Критерии | 0,0014 |
| Альтернативы по C1 | 0,0111 |
| Альтернативы по C2 | 0,0115 |
| Альтернативы по C3 | 0,0040 |
| Альтернативы по C4 | 0,0095 |

Все групповые `CR < 0,10`; максимальный индивидуальный `CR = 0,0224`. Для модели пересмотр сравнений не требуется. Полные матрицы и контрольные значения содержатся в [`results.json`](Данные%20и%20расчёты/results.json), краткая сводка — в [`ahp_summary.csv`](Данные%20и%20расчёты/ahp_summary.csv). По модельным данным МАИ рекомендует **A3**.

Геометрическое агрегирование индивидуальных суждений рассматривается в [исследовании Ramanathan и Ganesh о групповом МАИ](https://www.sciencedirect.com/science/article/pii/0377221794903565).
