# Сравнение методов и вывод

| Место | Концепция | TOPSIS CC | МАИ приоритет |
| ---: | --- | ---: | ---: |
| 1 | A3 Регистрация на студенческие события | **0,8228** | **0,3012** |
| 2 | A4 Расписание волонтёрских смен | 0,5794 | 0,2616 |
| 3 | A2 Планирование учебных групп | 0,3987 | 0,2278 |
| 4 | A1 Бронирование учебных помещений | 0,3160 | 0,2094 |

Оба метода дают один и тот же порядок альтернатив. Коэффициент близости TOPSIS и приоритет МАИ имеют разные определения и масштабы, поэтому сравнивать их абсолютные значения между методами нельзя.

**Предварительная рекомендация для модельного сценария — A3.** Концепция получает высокие оценки по всем четырём критериям. У A2 сильная реализуемость, у A4 — пригодность для планирования, но их преимущества по отдельным критериям не компенсируют общий баланс A3. Сценарии A3 ограничены одним факультетом и не включают платежи, что удерживает объём MVP в пределах 10–15 Use Cases.

## Устойчивость внутри модели

Расчёт повторён четыре раза с исключением одного модельного профиля. Во всех случаях оба метода сохраняют порядок `A3 → A4 → A2 → A1`. Этот тест показывает устойчивость к удалению одного **из выбранных модельных наборов**, но не является проверкой на реальных оценках команды.

| Исключённый профиль | TOPSIS | МАИ |
| --- | --- | --- |
| M1 | A3 → A4 → A2 → A1 | A3 → A4 → A2 → A1 |
| M2 | A3 → A4 → A2 → A1 | A3 → A4 → A2 → A1 |
| M3 | A3 → A4 → A2 → A1 | A3 → A4 → A2 → A1 |
| M4 | A3 → A4 → A2 → A1 | A3 → A4 → A2 → A1 |

## Что требуется перед окончательной сдачей

1. Получить независимые оценки четырёх реальных участников, если преподаватель согласует состав команды. В исходном задании указаны три человека.
2. Повторить расчёт и обновить DOCX, XLSX и эти таблицы при изменении исходных чисел.
3. Добавить ссылку на отдельный проект YouGile с исполнителями, периодами и чистым временем каждой работы. Папка таск-трекера в этом репозитории не создаётся.

Представленные числа — корректный и воспроизводимый **демонстрационный** расчёт. Они не подтверждают, что команда уже провела требуемое индивидуальное экспертное оценивание или приняла окончательное решение.
