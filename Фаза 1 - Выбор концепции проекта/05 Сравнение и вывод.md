# Сравнение методов и вывод

| Место | Концепция | TOPSIS CC | МАИ приоритет |
| ---: | --- | ---: | ---: |
| 1 | A3 Регистрация на студенческие события | **0,8228** | **0,3012** |
| 2 | A4 Расписание волонтёрских смен | 0,5794 | 0,2616 |
| 3 | A2 Планирование учебных групп | 0,3987 | 0,2278 |
| 4 | A1 Бронирование учебных помещений | 0,3160 | 0,2094 |

Оба метода дают один и тот же порядок альтернатив. Коэффициент близости TOPSIS и приоритет МАИ имеют разные определения и масштабы, поэтому сравнивать их абсолютные значения между методами нельзя.

**Первое место по обоим методам заняла A3.** Концепция получила высокие оценки по всем четырём критериям. A2 лидирует по реализуемости, A4 — по пригодности для планирования, однако суммарный результат A3 выше. Функциональность A3 ограничена событиями одного факультета и не включает платежи; объём MVP соответствует 10–15 Use Cases.

## Устойчивость внутри модели

Расчёт повторён четыре раза с исключением одного сценарного профиля. Во всех случаях оба метода сохраняют порядок `A3 → A4 → A2 → A1`. Устойчивость установлена в пределах использованного набора оценок.

| Исключённый профиль | TOPSIS | МАИ |
| --- | --- | --- |
| M1 | A3 → A4 → A2 → A1 | A3 → A4 → A2 → A1 |
| M2 | A3 → A4 → A2 → A1 | A3 → A4 → A2 → A1 |
| M3 | A3 → A4 → A2 → A1 | A3 → A4 → A2 → A1 |
| M4 | A3 → A4 → A2 → A1 | A3 → A4 → A2 → A1 |

## Границы результата

Расчёт выполнен на сценарных значениях, без индивидуального опроса участников команды. Итог A3 зависит от этих исходных оценок. Фактический состав команды — четыре человека, в исходном задании указана группа из трёх.

Учёт работ находится на отдельной [доске YouGile](https://ru.yougile.com/board/nb0783gl8x30). В репозитории представлены материалы выбора концепции; папки таск-трекера нет.
