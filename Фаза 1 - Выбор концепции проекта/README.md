## Проверка и пересчёт

Откройте [книгу Excel](Данные%20и%20расчёты/Фаза%201%20Экспертные%20оценки.xlsx). Листы «Эксперт 1–4» содержат модельные исходные оценки. Лист «TOPSIS» показывает групповые тройки, нормировку, идеалы, расстояния и коэффициенты близости. Лист «МАИ» показывает пять групповых матриц, приоритеты и коэффициенты согласованности. «Итог» ссылается на расчётные листы. При изменении чисел в анкетах формулы книги обновляют результаты; текстовые отчёты после этого нужно сверить с книгой и обновить вручную.

Сценарий не заменяет независимую экспертную оценку членов команды. [Таск-трекер YouGile](https://ru.yougile.com/board/nb0783gl8x30) ведётся отдельно от репозитория. В исходном задании указана группа из трёх человек; состав из четырёх требуется согласовать с преподавателем.
