# Фаза 1 Выбор концепции проекта

Четыре альтернативы оценены по четырём критериям. Расчёт основан на четырёх сценарных профилях M1–M4. Полученный порядок в обоих методах: **A3 → A4 → A2 → A1**.

## Расчётная книга

[Книга Excel](Данные%20и%20расчёты/Фаза%201%20Экспертные%20оценки.xlsx) содержит исходные оценки на листах «Эксперт 1–4». Лист «TOPSIS» содержит групповые тройки, нормировку, идеалы, расстояния и коэффициенты близости. На листе «МАИ» представлены пять групповых матриц, приоритеты и коэффициенты согласованности. Лист «Итог» связан формулами с расчётными листами.

Оценки заданы как сценарные значения, без опроса участников команды. Учёт задач ведётся на отдельной [доске YouGile](https://ru.yougile.com/board/nb0783gl8x30). Фактический состав команды — четыре человека; в исходном задании указаны три.
