# Фаза 1 Выбор концепции проекта

Четыре альтернативы оценены по четырём критериям. Для демонстрационного расчёта использованы четыре **модельных** профиля M1–M4. Итоговый порядок в обоих методах: **A3 → A4 → A2 → A1**.

| [02 Модельные оценки](02%20Модельные%20оценки.md) | Правила моделирования, исходные оценки и ограничения |

| [05 Сравнение и вывод](05%20Сравнение%20и%20вывод.md) | Сопоставление и рекомендация |
| [Данные и расчёты](Данные%20и%20расчёты/) | JSON, CSV, скрипт, заполненная анкета и DOCX-отчёт |

## Воспроизведение

Из папки `Данные и расчёты` запустите `python calculate_phase1.py`. Скрипт использует только стандартную библиотеку Python и обновляет `expanded_inputs.json`, `results.json`, `sensitivity.json`, `topsis_summary.csv`, `ahp_summary.csv`. Заполненная книга Excel и DOCX-отчёт являются проверенными снимками этого расчёта. Если меняются входные оценки, обновите их отдельно после запуска скрипта.

Сценарий не заменяет независимую экспертную оценку членов команды. Таск-трекер хранится отдельно в YouGile. В исходном задании указана группа из трёх человек; состав из четырёх требуется согласовать с преподавателем.
